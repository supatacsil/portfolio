About

Hi, I'm Davey — a program manager and marketing & communications strategist. I've had a very colorful career, which I'm proud of.

I've run paid, email, and social for a subscription platform built for working DJs (BPM Music). At Comic-Con International, I built a national membership program from scratch and raised over $1M in its first year. I've built a strong foundation for how I run marketing and communications programs: start with the audience, test the message, and measure what actually happened.

What's changed is how I deliver. I'm the connecting point between teams, I manage decisions that never got written down, and I build resilient systems that close the gaps. As AI has advanced, I increasingly automate the parts that don't need a human touch: agent-powered workflows, automated data hygiene, and dashboards that assemble themselves.

Outside of work, I love street photography, traveling, drumming, and cooking.
